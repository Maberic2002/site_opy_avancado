# Tópico 4 - Espaçamento

## O que mudou

- Margens e paddings criam ritmo entre header, carrossel, cards e footer.
- Os componentes usam espaçamentos internos previsíveis para facilitar a leitura.
- Em telas menores, os espaços são reduzidos para preservar o conteúdo essencial.

## Aplicação no projeto

O espaçamento responsivo está concentrado nas regras de [`style.css`](../../style.css), especialmente nos contêineres e media queries.

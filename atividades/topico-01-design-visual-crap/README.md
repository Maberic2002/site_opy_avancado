# Tópico 1 - Princípios de Design Visual (CRAP)

## O que mudou

- **Contraste:** títulos, CTAs dourados e textos claros destacam as ações principais.
- **Repetição:** a paleta verde, creme, dourado e laranja se repete em header, cards, botões e footer.
- **Alinhamento:** cabeçalho, conteúdo e rodapé usam contêineres e grades consistentes.
- **Proximidade:** cada card agrupa título, descrição e botão relacionados.

## Aplicação no projeto

Os estilos estão centralizados em [`style.css`](../../style.css), evitando estilos visuais diferentes entre as páginas.

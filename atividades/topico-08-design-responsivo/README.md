# Tópico 8 - Design Responsivo

## O que mudou

- Dashboard organizado com CSS Grid em header, sidebar, conteúdo e footer.
- Cards e gráfico usam largura fluida e se reorganizam abaixo de 768px.
- Imagens e blocos respeitam `max-width: 100%`.

## Aplicação no projeto

A home usa grades fluidas, carrossel com largura total e media queries existentes em `style.css`.

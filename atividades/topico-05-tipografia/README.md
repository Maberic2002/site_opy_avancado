# Tópico 5 - Tipografia

## O que mudou

- A interface usa Inter para textos e Noto Serif para títulos de destaque.
- Tamanhos, pesos e alturas de linha diferenciam títulos, descrições, links e legendas.
- Títulos fluidos usam `clamp` em áreas que precisam se adaptar à tela.

## Aplicação no projeto

As fontes são carregadas em [`index.html`](../../index.html) e aplicadas por hierarquia em [`style.css`](../../style.css).

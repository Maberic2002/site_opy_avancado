# Tópico 3 - Grid System

## O que mudou

- Cards, produtos, personagens e áreas internas usam CSS Grid.
- As colunas têm `gap` consistente e se adaptam ao espaço disponível.
- Layouts com duas ou três áreas passam para uma coluna em telas menores.

## Aplicação no projeto

Exemplos principais: `.menu-grid-top`, `.store-grid-2`, `.characters-grid` e `.santuario-shell` em [`style.css`](../../style.css).

# Tópico 7 - Cores

## O que mudou

- **Primária:** verde escuro da marca para header, footer e ações principais.
- **Secundárias:** creme, dourado e laranja para fundos, destaques e promoções.
- **Neutras:** branco, bege e cinzas para leitura, bordas e superfícies.
- **Semânticas:** estados de sucesso, carregamento e erro aparecem no chatbot.

## Aplicação no projeto

As cores de marca ficam documentadas nas variáveis do `:root` de [`style.css`](../../style.css), e os estados do assistente usam `data-state` em [`chat.js`](../../chat.js).
